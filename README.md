# Family Reward Game

A family reward web app where parents award or deduct points and children spend points to unlock collectible characters and evolve them.

## Stack
- React + TypeScript + Vite
- Cloudflare Workers
- Cloudflare D1
- Tailwind CSS
- Zod

Development is split into phases. Phase 0-1 establishes project structure, architecture, D1 schema, migrations, seed data, and the React shell.
