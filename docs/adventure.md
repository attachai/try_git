# การเดินทางของซาโตชิ

โหมดเด็กเล่นกับระบบเองจากเมนู **ผจญภัย** ไม่ต้องเปิดห้องหรือรอผู้ปกครอง

## กติกาที่เพิ่มแล้ว

- 120 ด่านเรียงลำดับ: คันโต โจโต โฮเอ็น ชินโอ อิชชู คาลอส อโลลา กาลาร์ ภูมิภาคละ 15 ด่าน เป็นเส้นทางเกมที่ได้แรงบันดาลใจจากการเดินทาง ไม่ใช่การจำลองตอนของการ์ตูน
- บอสทุก 5 ด่านและลีกทุก 15 ด่าน ความยากเพิ่มตามระดับ สถิติ และจำนวนคู่แข่ง รวมสภาพสนามและอากาศจากระบบต่อสู้เดิม
- เลือกโปเกมอน 1–3 ตัวก่อนแข่ง ตรวจธาตุหลักและธาตุรอง ตั้งแต่ภูมิภาคที่ 5 บางบอสต้องมี 2 ธาตุครบในทีม ห้ามเลือกชนิดเดียวซ้ำ
- มีเพื่อนให้ยืมฟรีครอบคลุมธาตุที่สนามต้องการ ระดับและความหายากของเพื่อนยืมเพิ่มตามความก้าวหน้า ไม่มีการมอบเข้าคอลเลกชันถาวร
- วันละ 5 **ครั้งเริ่มต่อสู้** ต่อเด็ก: รวมแพ้ เล่นซ้ำ และยอมออกจากการต่อสู้ ไม่สะสมโควตาข้ามวัน รีเซ็ต 00:00 Asia/Bangkok ควบคุมด้วย trigger ฐานข้อมูลเพื่อป้องกันคำขอพร้อมกัน
- ออกจากหน้าเกมหรือรีเฟรชแล้วกลับมาเล่นต่อได้โดยไม่ใช้โควตาเพิ่ม การต่อสู้ที่ค้างข้ามเที่ยงคืนยังเป็นครั้งของวันที่เริ่ม
- ซาโตชิได้รับ XP ครั้งแรกที่ผ่านด่าน และ 10 XP เมื่อแพ้ เลเวลเทรนเนอร์เพิ่มทุก 100 XP พร้อมฉายาตามด่านที่ผ่าน XP นี้แยกจากแต้มความดีและ XP โปเกมอนในคอลเลกชัน
- ผ่านด่านได้ 1 ดาว ทีมไม่หมดสติได้อีก 1 ดาว และจบไม่เกิน 15 เทิร์นได้อีก 1 ดาว เก็บผลที่ดีที่สุด เล่นซ้ำไม่รับ XP ชัยชนะเพิ่ม
- พาสปอร์ตมี 8 เหรียญภูมิภาค เป้าหมายหลังครบ 120 ด่านคือ 360 ดาว ไม่มีการริบความก้าวหน้าหากเว้นวันเล่น
- การต่อสู้ใช้ engine เดิม: โจมตี ท่าพิเศษ ตั้งรับ สลับตัว ไม้ตาย และ AI ตอบกลับในคำขอเดียว โหมดนี้ไม่มีไอเทมที่ต้องจ่ายแต้ม

## ข้อมูลและ API

Migration: `db/migrations/0025_adventure.sql` เพิ่ม progress, runs, records และ trigger สำหรับโควตา/การจบเกมพร้อมรางวัลใน transaction เดียวกัน

- `GET /api/adventure`: ความก้าวหน้า โควตาวันไทย เวลารีเซ็ต ดาวและเกมที่ค้าง
- `GET /api/adventure/roster?stageId=1`: โปเกมอนของเด็กและเพื่อนยืมที่เลือกได้
- `POST /api/adventure/start`: `{ stageId, team: [pickId] }`
- `POST /api/adventure/runs/:id/action`: `{ version, action, target? }`
- `POST /api/adventure/runs/:id/abandon`: จบเกมค้างโดยไม่คืนโควตา

ใช้ session เด็กฝั่ง server, ตรวจเจ้าของทุกการต่อสู้, version สำหรับป้องกันการเล่นคำสั่งซ้ำ, progress/stars/XP commit พร้อมผลการต่อสู้

## เปิดใช้งาน

Local migration ใช้ `npm run db:migrate:local` แล้ว `npm run dev`

ก่อนนำขึ้นระบบจริง ต้อง apply migration ใหม่กับฐานข้อมูลเป้าหมายผ่าน workflow เดิม จากนั้น build/deploy แอป การเปลี่ยนแปลงนี้ไม่ได้ deploy ระบบจริงให้อัตโนมัติ

## แนวคิดสำหรับรอบถัดไป (ยังไม่ได้ทำ)

1. สมุดบันทึกภาพเหตุการณ์และเพื่อนใหม่เมื่อจบแต่ละภูมิภาค
2. ภารกิจหมุนเวียนรายสัปดาห์ ใช้โควตา 5 ครั้งเดิม รางวัลเป็นของตกแต่งและสติกเกอร์
3. บทฝึกธาตุแบบจับคู่สั้น ๆ ที่ไม่มีการต่อสู้ หลังใช้โควตาหมด
4. ทีมโปรดและชุดแต่งตัวเทรนเนอร์ ปลดล็อกจากดาวสะสม
5. รายงานสรุปให้ผู้ปกครองเห็นสิ่งที่เด็กเรียนรู้และระยะเวลาเล่น

ควรปรับสมดุลคู่แข่งจากผลเล่นจริงก่อนเพิ่มเนื้อหายากขึ้น โดยรักษาเส้นทางเพื่อนยืมเพื่อไม่ให้การซื้อเป็นเงื่อนไขการผ่านด่าน
